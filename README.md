# STEAMLab — Química multisensorial para secundaria

**Repositorio sugerido:** `steamlab-quimica-multisensorial`

## Publicar
1. Crea el repositorio `steamlab-quimica-multisensorial` en GitHub (Public).
2. Sube **los cuatro archivos a la raíz**: `index.html`, `estilo.css`, `app.js` y `laboratorio.png`. **No los dejes dentro de una carpeta**.
3. Ve a Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Abre `https://luisctito-sketch.github.io/steamlab-quimica-multisensorial/` (si el usuario es `luisctito-sketch`).

## Uso
Abre la escena y toca los seis círculos luminosos para interactuar con modelos moleculares, elementos de la tabla periódica, escala de pH, mezclas, microscopio y estación sensorial segura. Cada uno activa una visualización, un sonido opcional, un breve reto y partículas animadas. Usa los controles para desactivar sonido o luces, pausar las animaciones, ajustar la velocidad y entrar en pantalla completa. Diseñado para PC y móvil (en móvil mejor horizontal).

## Propósito y seguridad
- Contenido de Química de secundaria, con especial atención a **«Estaciones del pH sin olores»**.
- Indicadores y colores **ilustrativos**, no mediciones exactas ni calibración de pH.
- No son reacciones reales ni instrumentos conectados.
- **No oler ni probar** reactivos, sustancias desconocidas ni muestras de laboratorio.
- Olfato y gusto se proponen únicamente como actividades separadas con **tarjetas ilustradas** de alimentos y plantas; no requiere inhalar ni consumir nada, y hay alternativas equivalentes para sensibilidades y alergias.
- Vincula las actividades digitales con papel indicador, observación y registro de resultados cualitativos supervisados por el docente.

La tecnología es un apoyo. El profesor conserva el timón y la IA amplía el horizonte.
